Use `--json` for structured output and `--help` on any command for its usage. Start with [installation and sign-in](/cli/install), or follow the guide to [start a run and save progress](/guides/save-progress).

## ultrametric

Company setup guidance and records for your project.

```text
ultrametric [options] [command]
```

| Option | Meaning | Choices | Required |
| --- | --- | --- | --- |
| `-v, --version` | output the version number |  | No |
| `--json` | Print a versioned JSON result; errors are JSON on stderr. |  | No |
| `--no-json` | Use text output even when settings default to JSON. |  | No |
| `--data-dir <directory>` | User home for settings, logs, and data (or ULTRAMETRIC_DATA_DIR). |  | No |
| `--environment <environment>` | API and login environment; local records stay in the selected data directory. | production, staging | No |

## ultrametric auth

Log in, check status, or log out.

```text
ultrametric auth [options] [command]
```

## ultrametric auth login

Open a browser and wait for login; --json returns a link for agent completion.

```text

```

## ultrametric auth complete

Check a pending login once and save the session after browser approval.

```text
ultrametric auth complete [options] <login-id>
```

## ultrametric auth status

Show login status.

```text
ultrametric auth status [options]
```

## ultrametric auth logout

Log out.

```text
ultrametric auth logout [options]
```

## ultrametric init

Install the Ultrametric documentation skill in a project for Codex and Claude Code.

```text
ultrametric init [options]
```

| Option | Meaning | Choices | Required |
| --- | --- | --- | --- |
| `--path <directory>` | Existing project directory (defaults to the current directory). |  | No |
| `--agent <agent>` | Agent skill location to install. | all, codex, claude | No |
| `--dry-run` | Preview changes without writing project files, settings, or logs. |  | No |
| `--force` | Replace an existing Ultrametric SKILL.md that differs from the bundled version. |  | No |

```text

```

| Option | Meaning | Choices | Required |
| --- | --- | --- | --- |
| `--process-version <number>` | Published process version (defaults to latest). |  | No |

| `--company <uuid>` | Resume a local company-profile record. |  | No |
| `--project <name>` | Project display name for ai-native-assessment. |  | No |

## ultrametric context get

Read hosted companies, runs, records, or explicit history.

```text
ultrametric context get [options]
```

| Option | Meaning | Choices | Required |
| --- | --- | --- | --- |
| `--file <path>` | API get input as JSON; use - for stdin. Cannot be combined with selectors. |  | No |
| `--collection <collection>` | Collection to browse. | companies, runs, records | No |
| `--organization <id>` | Require the organization selected for this login. |  | No |
| `--company <uuid>` | Hosted company ID. |  | No |
| `--run <uuid>` | Read one run and its next update key. |  | No |
| `--record <uuid>` | Read one complete record. |  | No |
| `--process <id>` | Filter runs by process. |  | No |
| `--query <text>` | Search current records. |  | No |
| `--history` | Read history for a selected run or record. |  | No |
| `--before-revision <number>` | History cursor from the previous page. |  | No |
| `--after <uuid>` | Collection cursor from the previous page. |  | No |
| `--limit <number>` | Page size; the API permits 1 to 25. |  | No |
