title: "Install and sign in"
description: "Set up the CLI for a terminal-capable agent."
---

The CLI requires Node.js 22.12 or later. Your agent can install it from a terminal, or you can run:

```sh
npm install -g ultrametric@latest
ultrametric --version
```

The same command updates an existing installation. With a Node version manager, install the CLI in the Node environment your agent uses.

## Sign in through your agent

Have your agent check the saved session:

```sh
ultrametric auth status --json
```

If you need to sign in, it can start login with:

```sh
ultrametric auth login --json
```

The result includes `verificationUriComplete`, `userCode`, `loginId`, `expiresAt`, and `retryAfter`. Open the returned verification link, confirm the code, and complete sign-in. Choose the account and workspace you want the agent to use.

After browser approval, your agent completes the login using the returned ID:

```sh
ultrametric auth complete LOGIN_ID --json
```

Replace `LOGIN_ID` with `data.loginId` from the login response. Each completion request checks once. If the result is still pending, wait for `retryAfter` seconds before checking again. Start a new login if the code expires.

If you are working directly in the terminal, `ultrametric auth login` opens the browser and waits for completion. With `--json`, the agent gets the link and controls completion without an interactive prompt.

## Agent skills

The CLI can add Ultrametric instructions to a project for Codex and Claude Code. From the project directory, preview the files, then install them:

```sh
ultrametric init --dry-run --json
ultrametric init --json
```

Use `--agent codex` or `--agent claude` for one client, and `--path` to choose another existing project directory. Review conflicting files before using `--force` to replace them.

After updating the CLI, run `init` again to refresh the project's installed instructions.

Start a fresh agent session in the project to load the installed instructions. The agent needs terminal access to the CLI and the sign-in above for hosted operations.
