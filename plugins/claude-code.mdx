---
title: "Use with Claude Code"
description: "Install Ultrametric project instructions for Claude Code."
---

Make the [CLI](/cli/install) available in the terminal environment used by Claude Code. From your project directory:

```sh
ultrametric init --agent claude --dry-run --json
ultrametric init --agent claude --json
```

The first command previews the change. The second writes:

```text
.claude/skills/ultrametric/SKILL.md
```

The installer uses `claude` as the target value. Add `--path` to choose a different existing project directory. Review a conflicting file before using `--force` to replace it.

Start or refresh a Claude Code session in the project, then ask:

```text
Use Ultrametric to help with this project's company setup.
Find the relevant process and reuse what we already know.
```

If the skill is not available, check the file and open a fresh session in that project. The agent can also inspect `ultrametric --help` directly.

Complete [CLI sign-in](/cli/install) for hosted operations. If you want remote tools rather than terminal commands, configure [MCP](/mcp/connect) separately.
