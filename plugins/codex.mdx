> Internal documentation draft. Target-path and no-write preview verified locally; Codex loading not tested.

From an existing project directory with CLI 0.4.1 available:

```sh
ultrametric init --agent codex --dry-run --json
```

The proposed target is:

```text
.agents/skills/ultrametric/SKILL.md
```

Inspect the returned `files` and `conflicts`. When installation is intended, run the same command without `--dry-run`. A conflicting file needs review before replacement with `--force`. That flag changes the selected Ultrametric skill file.

The skill ships with the package and installs offline. It supplies guidance; it does not install the executable, authenticate the user, or add an MCP connection. Confirm the skill is available in a fresh project session before advertising the integration as tested.
