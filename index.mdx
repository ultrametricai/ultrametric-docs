---
title: "Use Ultrametric with your agent"
description: "Get process guidance and carry company context between sessions."
---

Ultrametric gives your agent process instructions, result formats, and saved company context. Tell your agent what you want to achieve. It can find a relevant process, use what it already knows about your project, and keep track of the work.

For example:

```text
Use Ultrametric to help me set up the company behind this project.
Start with what you already know, and ask me for any missing details.
```

## Choose a connection

Use the **CLI** when your agent can run terminal commands and work with project files. Use **MCP** when your agent supports remote tools through an MCP connection.

| Connection | Setup | What you need |
| --- | --- | --- |
| CLI | [Install and sign in](/cli/install) | Terminal access and Node.js 22.12 or later |
| MCP | [Connect Ultrametric](/mcp/connect) | An agent host with remote MCP and OAuth support |

Both connections use the same process service and hosted company records. Sign in to the same account and organization to continue work across them.

## Start with a process

Follow the [quickstart](/quickstart) to find a process and read its guide. The agent uses the guide with your context and the tools available in your session. Available processes can differ by account.

As work progresses, [save decisions and results](/guides/save-progress). In a later session, [find the saved run](/guides/resume-work) and continue from it.

If you use Codex or Claude Code, you can also [add project skills](/plugins/overview) so your agent has Ultrametric instructions in the project.
